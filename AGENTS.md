## Impeccable UI workflow

For UI implementation or review, follow [IMPECCABLE.md](IMPECCABLE.md) and the repository-local `.agents/skills/impeccable/SKILL.md`. Read established product/design context first; use scoped shape, critique and platform-appropriate audit passes. Existing safety, privacy, SEO, editorial, test and deployment rules remain binding. For non-UI work, use conditional guidance rather than creating a UI task.
